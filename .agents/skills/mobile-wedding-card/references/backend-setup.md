# Google Apps Script & Google Sheets Backend Guide

This guide explains how to set up the serverless backend for RSVP (참석 여부) and Guestbook (방명록) features.

---

## 1. Google Spreadsheet Setup

1. Create a new Google Spreadsheet in Google Drive.
2. Name the spreadsheet (e.g. `결혼식 방명록 및 참석여부`).
3. Create two sheets (tabs) with exact names:
   - **`참석여부`**: For RSVP records.
   - **`방명록`**: For guestbook messages.

### Spreadsheet ID Extraction
The URL looks like:
`https://docs.google.com/spreadsheets/d/1Dkibjj02eaZFiDoFsatUPtn4ptnZyD-qU414oX4fp6Q/edit#gid=0`

The ID is the segment between `/d/` and `/edit`:
`1Dkibjj02eaZFiDoFsatUPtn4ptnZyD-qU414oX4fp6Q`

---

## 2. Google Apps Script Deployment

1. Inside the Google Spreadsheet, click **Extensions (확장 프로그램) > Apps Script**.
2. Delete default code and paste the complete content of [`google_apps_script.js`](../templates/google_apps_script.js).
3. Replace the spreadsheet ID in line 6 and 36:
   ```javascript
   var spreadsheet = SpreadsheetApp.openById("YOUR_SPREADSHEET_ID_HERE");
   ```
4. Click **Deploy (배포) > New deployment (새 배포)**:
   - **Type (유형 선택)**: Web App (웹 앱)
   - **Description**: `v1`
   - **Execute as (다음 사용자로 실행)**: `Me (나)`
   - **Who has access (액세스 권한이 있는 사용자)**: `Anyone (모든 사용자)` *(Important: must be Anyone so unauthenticated guests can submit)*
5. Authorize permissions when prompted by Google.
6. Copy the **Web App URL** (starts with `https://script.google.com/macros/s/.../exec`).
7. Paste this URL into `data/config.json`:
   ```json
   "rsvp_api_url": "https://script.google.com/macros/s/.../exec"
   ```

## 3. Data Structure & Security

### RSVP Sheet (`참석여부`)
Columns automatically generated by script:
- `접수 일시`: Timestamp
- `구분`: 신랑측 / 신부측
- `성함`: Guest name
- `참석 여부`: 참석 / 불참
- `동반 인원`: 1명 / 2명 / 3명 / 4명 이상
- `식사 여부`: 식사함 / 식사안함 / 미정
- `축하 메시지`: Optional message

### Guestbook Sheet (`방명록`)
Columns automatically generated by script:
- `작성 일시`: Timestamp
- `성함`: Name
- `비밀번호`: 4-digit password (used only for row deletion)
- `메시지`: Congratulatory message

> [!IMPORTANT]
> **Password Security**: `doGet` omits the password column index when returning JSON data to the browser. Guests never receive other guests' deletion passwords.
